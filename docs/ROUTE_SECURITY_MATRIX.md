## Authorization Invariants Enforced

1. **Zero Self-Assigned Privileges**: Roles (`ADMIN`, `DOCTOR`, `HEALTH_WORKER`) originate exclusively from cryptographic tokens signed with server secrets.
2. **Patient Data Isolation (BOLA/IDOR)**: Patients (`Role.PATIENT`) cannot query or modify another patient's records or access other scans via `/results/<filename>`.
3. **Session Binding Immutability**: Mid-session manipulation of `patient_id` or `eye` fails closed with `HTTP 409 Conflict`.
4. **Device Queue Isolation**: Edge field units cannot inspect other devices' synchronization queues.
5. **Fail-Closed Demo Sandbox**: Any demo attempt against real patient IDs returns `HTTP 400 Bad Request`; running demo when `DEMO_MODE=False` returns `HTTP 403 Forbidden`.
